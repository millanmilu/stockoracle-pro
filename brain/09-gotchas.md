# 09 — Gotchas (aam galtiyaan + fix)

1. **Intraday SQLite me daal diya?** → Kabhi mat karo. Sirf memory cache. Test `test_data_invariants.py` pakad lega.
2. **`dropna` se candles gayab?** → `enrich_stock_dataframe` me dropna mana hai. `min_periods=1` use karo.
3. **Weekend pe candle ban gayi?** → `get_combined_stock_data` ka weekday+9AM check dekho.
4. **WS me fake price?** → Hardcoded fallback hatao, historical close use karo. Test: `test_ws_broadcast_fallback.py`.
5. **Chart me gap = bug?** → Nahi. Bada outage gap whitespace ke roop me dikhna chahiye (lightweight-charts behavior). Sirf <=30 slots fill hote hain.
6. **ML 503 de raha?** → `require_real_data` ne synthetic block kiya = broker offline ya history nahi. Pehle `/api/stocks/session` dekho.
7. **Heuristic prediction pe confidence?** → "Uncalibrated" label me confidence None hota hai — UI me "model trained nahi" dikhao.
8. **Vault decrypt fail?** → Prod me JWT_SECRET badla hoga. Purani rows legacy key se padhi jaati hain; nahi khule to key wapas lao.
9. **CORS/API 403?** → Prod me `X-API-Key` header bhejo; `?api_key=` deprecated hai.
10. **Terminal khaali?** → `python verify_terminal.py` chalao; OpenBB optional hai, native engine fallback hai.
11. **Crypto seed DB me gaya?** → `_generate_crypto_seed_data` sirf charts ke liye hai — persist mat karo (DB me gaya to `sqlite` source banke ML me ghus jayega). Guard list me `crypto_seed` hai.
12. **52W high/low unknown?** → `current*1.15` jaisa estimate mat banao — `null` bhejo.
13. **Naya router bina auth?** → `dependencies=[Security(verify_api_key)]` lagao (research/ml pattern). Prod me `API_KEY` unset ho to startup par loud error aata hai.
14. **Tape me hardcoded price LIVE lag raha?** → Kabhi mat karo (AGENTS.md §4). Backend `ticker-tape` hamesha BTC/GOLD rows deta hai (LIVE / STATIC / UNAVAILABLE) — frontend injection dead code hai, hatao. Baseline skeleton `price: null` rakho, outage `OFFLINE` badge se dikhao.
15. **Topbar har tick pe re-render?** → `useStore(s => s.livePrices)` poora object subscribe karta hai (BTC dozens/sec). Tape ke liye 1s `getState()` snapshot kaafi hai.
16. **Tape click se chart blank?** → `NIFTY50` ka universe token None hai (verify: `get_stock_universe_token`) — tape se uspe navigate mat karao.
17. **Left-pan pe purana data chahiye?** → Default bounded load hi rakho; `BACKFILL_LEVELS` + `onNeedOlderData` (30-bar edge trigger) left me prepend karta hai. Viewport shift-compensate hota hai (`ChartCanvas` prepend branch) — `fitContent` mat chalao warna jump hoga. Backfill fail silent rehta hai (badge nahi), replay/loading me blocked, exhaustion pe stop.
18. **Holiday pe fake live candle ban raha?** → Clock gate (09:15–15:30 IST) holidays nahi dekhta. Equity candle gating `canUpdateLiveCandle` (`chartHelpers.js`) karta hai: explicit `is_live:false` = veto, flag missing = legacy clock, crypto bypass. Backend broadcaster holiday pe verified EOD fallback `is_live:false` bhejta hai (AGENTS.md §4). Test: `chartHelpers.test.js`.
19. **Restart ke baad chart me bada trailing gap (live candle ke peeche khaali jagah)?** → Chart load backend warmup se race karke DB-only truncated tail pakad leta hai; live ticks sirf aage judte hain isliye gap refresh tak rehta hai. Pehle backend `/api/stock/<sym>/history` me continuity verify karo (gap nahi → data healthy, chart stale hai). Fix: hard refresh. Auto-recovery: `useHistoryData.js` ka stale-tail guard (fallback `data_source` + purani tail → 30s timer, max 3 silent refetch, live tail/viewport preserved; pure logic `shouldRefetchStaleTail` — test: `chartHelpers.test.js`). Warmup race kam karne ke liye preloader polite hai (`fetch_crypto_data(..., polite=True)` page-walk spacing + timeframe gap) — user `/history` kabhi throttle nahi hota.
19. **Intraday history 404 jab broker down ho (data DB me hai)?** → `fetch_stock_data` step 4b stale `intra_db` ko `sqlite_stale` source se lautata hai (cursor path ke `base_win` last resort jaisa). Daily `db_df` fallback intraday path par kabhi set nahi hota tha — yehi purana bug tha. Test: `test_intraday_stale_fallback.py`.
20. **Drawing reload pe gayab ho rahi?** → `repairDrawings` (`drawingToolUtils.js`) ka anchor count **catalog spec se** aana chahiye (`spec.points`), hardcoded 3 nahi — warna saari 2-point tools (FRVP, fib fan, ellipse, triangle, arc, fib circle, extended line, date/price range, regression trend, bars pattern) reload pe drop ho jaati hain aur localStorage `[]` ho jaata hai. Test: `drawingRepair.test.js` (Node me `drawingToolCatalog.js`/`drawingToolUtils.js` import karne ke liye dono pure modules hain — `PINS_STORAGE_KEY` catalog me hai, React file import mat karo).
21. **Chart pe drawing tool place karte hi "Cannot read properties of undefined (reading 'x')"?** → Renderer har extended tool ke liye partial-anchor preview handle kare. `renderHeadShoulders` me `if (!ls || !rs) return null` guard hai — 5-anchor tool ka preview 1–4 anchors ke saath render hota hai placement ke dauran. Baaki pattern renderers (`if (!c) return null`) same contract follow karte hain; naya renderer likhne pe pehle ye guard rakhna. Test: `patternRenderers` preview path CDP se verify hua (1–5 anchor clicks, 0 exception).
